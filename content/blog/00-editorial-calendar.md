# Editorial calendar

**Purpose:** The 15-20 hero blog posts that drive Michele's first-year ranking signal and Wisdom Flows newsletter cadence. Each post is a scoped project with a target keyword, an ICP pain point, a hook, a CTA hierarchy, and a target word count.

**Cadence:** One post every 2-3 weeks. Three hero posts ship at launch (Week 1). The remaining 12-17 ship on cadence across Weeks 2-52.

**Voice register:** Michele. See `content/brand/voice-guide.md` before drafting.

## Draft workflow (per post)

1. Michele's voice notes -> Wispr Flow -> Google Doc.
2. Claude / Gemini drafts a first pass using the voice corpus.
3. Michele edits.
4. Voice audit against `content/brand/voice-guide.md`.
5. SEO / GEO audit against `research/02-search-optimization-landscape.md`.
6. Post + schema push to the repo.
7. Vercel auto-deploys.
8. Newsletter (Wisdom Flows) sends the same day.

## Refresh cadence

Every post gets a refresh at the 6-month and 12-month mark. Update `dateModified` in schema. Add one paragraph reflecting new learning.
