# Bios directory

Four canonical bios at four depths. Pull from these anywhere on the site, in a program page, in HoneyBook, in an event program, or in press copy.

| File | Length | Best used for |
|---|---|---|
| `one-line.md` | 1 sentence | Byline, social profile, form title field |
| `short.md` | ~60 words | Podcast guest, program block, event program |
| `medium.md` | ~150 words | About page snippet, longer program block |
| `long.md` | ~300 words | Speaker one-sheet, press kit, foreword byline |

## Rules for using these bios

- **Spell Michele with one L.** Always.
- **Do not call Michele a therapist, counselor, or licensed mental health professional.** She holds none of those credentials.
- **Do not add "founder and CEO" language.** Michele is founder and Executive Director of Releasing Generations, and founder of Michele Okimura LLC. Not "CEO."
- **Keep the faith context in every bio.** The pastoral history is a real qualification. Do not strip it from an LLC-context bio.
- **Do not over-promise outcomes.** No "bestseller," no "guaranteed publisher deal," no "millions of readers."
