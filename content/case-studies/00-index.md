# Case studies: Michele's authored body of work

**Purpose:** The catalog and template for the case-study pages that make up `/works` on the site. Each authored work is treated as a case study of Michele's ability to produce transformational written content. Together they form the primary authority stack.

**Why case studies, and not coaching testimonials?** The Brave Purpose Author Method is a new offering. Nancy Webb is client #1. Rather than lean on coaching-client testimonials Michele has not yet accumulated, the site leads with the durable proof she already has: fifteen years of authored, published, produced work. Each piece is a case study of the same method she now teaches.

## Layout reference

The case-study page structure is modeled on `createchurchmedia.com/case-studies/<slug>`. See `research/09-createchurchmedia-layout-analysis.md` for the pattern in detail.

## Case study page structure (locked template)

Every case-study file in this directory follows the structure below. Copy `_TEMPLATE.md` as a starting point when adding a new work.

1. **Hero.** Cover / hero image, work title, publication date, category (book / curriculum / workshop / etc.), sidebar metadata (format, publisher, ISBN, purchase link).
2. **Positioning statement.** One or two sentences: what this work does for readers.
3. **Origin story.** Why Michele wrote it, what she was solving.
4. **Structure and methodology.** How she structured it, what patterns she used. This is where Brave Purpose Author Method credibility comes from because it shows she has done what she is now coaching others to do.
5. **Reach and impact.** Readers, participants, testimonials if any (leave placeholder markers where content will be harvested from Michele's inbox in a parallel task).
6. **What she learned that now feeds the Method.** The bridge from the past work to the coaching offering.
7. **Purchase / access link.**

## Content-harvesting checklist

Placeholders in each case study marked with `[TODO: from Michele's inbox]` will be populated by a parallel Gmail research task mining Michele's email for:

- Reader letters and testimonials
- Participation numbers from conferences and workshops
- Notable placements (schools, churches, ministries using the work)

Each case-study file has a `## To be harvested` section at the end listing the specific missing content.
