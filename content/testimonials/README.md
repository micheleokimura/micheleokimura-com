## Directory structure

- `authored-works/` -> testimonials for specific books, curricula, and journals (one folder per work, matching the case-study slugs)
- `speaking/` -> testimonials from speaking engagements
- `coaching/` -> The Brave Purpose Author Method testimonials, once engagements close
- `consent-log.md` -> record of consent captured for each testimonial

## Format for each testimonial

```yaml
---
name: Full name
title: Their title / role / organization
date: YYYY-MM-DD
source: [book title / speaking engagement / coaching program]
consent: verbal | written | signed release
quotable: yes | no
---

The quote itself, in the source's own words.
```

## Do not publish

- Without documented consent.
- Verbatim quotes that identify the source without their explicit written permission.
- Anonymized quotes without noting they have been anonymized.
- Quotes older than 3 years without re-confirming consent.
